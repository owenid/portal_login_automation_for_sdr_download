AWS architecture reference

Gradwell CDR Pipeline

A scheduled Lambda that logs into the Gradwell SSO/Admin portal, downloads the latest SDR call-detail-record file, and stores it in S3 — running unattended on the 1st of every month.

System diagram

What each component does

Amazon EventBridge
Trigger
Fires the Lambda on cron(1 9 1 * ? *) — 09:01 UTC on the 1st of every month (09:01 UK time in GMT; 10:01 UK local during BST) — via a Schedule rule attached directly to the function. Nothing else in the system runs unless this rule fires, or someone invokes the function manually for testing.
AWS Lambda
Compute
CdrDownloaderFunction — the entire mechanism runs inside one invocation. Node.js 22.x on x86_64, 2048 MB memory, a 180-second timeout, and 1024 MB of /tmp. Drives a real headless Chromium session via playwright-core and @sparticuz/chromium to perform the login, navigation, and file download exactly as a person would in a browser.
IAM execution role
Access control
Scoped narrowly on purpose: secretsmanager:GetSecretValue only on the named secret's ARN pattern, and s3:PutObject limited to the cdr/* and debug/* prefixes of the CDR bucket — not the bucket as a whole. The function holds no broader AWS permissions — it can't read other secrets, write outside those two prefixes, or touch other buckets.
AWS Secrets Manager
Secret
prod/AdminPortal/Gradwell holds the portal username and password as a JSON key pair. Pre-existing — this stack reads it but never creates, owns, or writes its value. Fetched fresh on every invocation; never cached, logged, or written to disk.
Gradwell SSO / Admin Portal
External system
Not part of this AWS account — a third-party customer/reseller portal reached over the public internet. The Lambda logs in at sso.prod.gradwell.com, lands on admin.prod.gradwell.com/home, then /sdrs, where a table sorted newest-first lists each billing period. On the 1st of the month it first confirms the newest row's End Date is the last day of the previous month — the period that should have just completed — and throws an error instead of downloading if Gradwell hasn't published it yet; otherwise it clicks the first row's download control to fetch the latest CDR file.
Amazon S3
Storage
CdrBucket — private, SSE-AES256 encrypted, all public access blocked. Downloaded files land under cdr/<year>/<month>/; optional per-step debug screenshots land under debug/ and auto-expire after 30 days via a lifecycle rule.
Amazon CloudWatch Logs
Observability
Every invocation's console output — including full Playwright error traces and the 1st-of-month freshness check's error message — lands automatically in the function's log group. The source of truth for why a run succeeded or failed.
CdrDownloaderErrorsAlarm
Alerting
CloudWatch alarm on the function's Errors metric (namespace AWS/Lambda). Uses a 1-day evaluation period with TreatMissingData: notBreaching, since the function only runs once a month — an idle day reads as "no data," not a failure. Publishes ALARM/OK transitions to the SNS topic named by DatadogForwarderTopicArn, which the existing Datadog Forwarder consumes to raise a monitor event.
RotationFunction
Compute
A second Lambda implementing AWS Secrets Manager's custom rotation contract (createSecret / setSecret / testSecret / finishSecret) on a 90-day RotationSchedule. Since Gradwell has no rotation API, it drives the same email-based reset flow a person would use — see Credential rotation flow below.
Microsoft Graph app registration
External system
An Azure AD App Registration with the application permission Mail.Read, restricted by an Exchange Application Access Policy to exactly one Microsoft 365 mailbox — the one that receives Gradwell's reset emails. Its credentials are held in a separate Secrets Manager secret (GraphApiCredentialsSecretName), never in code or environment variables.

! Alerting is wired but not fully activated. CdrDownloaderErrorsAlarm watches the function's Errors metric and publishes ALARM/OK state to an SNS topic that the Datadog Forwarder consumes — but the DatadogForwarderTopicArn stack parameter still needs the real Forwarder topic ARN before those notifications actually reach Datadog. Note that a legitimate ALARM on the 1st of the month can now also mean "Gradwell hasn't published this period yet" rather than a real bug — check the CloudWatch Logs message before treating it as an incident.
! Rotation is not yet runnable. RotationFunction is deployed but cannot succeed until IT provisions the Azure AD app registration (Mail.Read, admin-consented) and the Exchange Application Access Policy scoping it to one mailbox, and the resulting credentials are populated into the GraphApiCredentialsSecretName secret. The reset-flow selectors and reset-email link extraction are also unverified against the live site — the same caveat the download flow carried before it was tuned against the real portal.
